# 单机卡牌游戏：事件系统设计

> 状态：v1（2026-10-17，随技能编辑器改进轮立项——"入场动画结束后结算挂起效果"是第一个使用场景）。
> 定位：**项目级全局事件系统**，独立程序集（`Scripts/GameEvents/`）、独立文档；战斗核心、表现层、UI、局外都是它的潜在发送方/订阅方。
> 标注约定：【本期】=本轮实现；【预留】=设计已留位、后续再做。

---

## 一、目标与非目标

**目标**：
- 提供跨模块、**编译期全检查**的事件通道（不用字符串、不用反射）
- 本期承接"表现层 → 战斗核心"的时序回调：入场动画结束 → 放行挂起的效果组（见《战斗核心框架设计》"表现挂起"节）
- 为后续演出时序类需求（死亡动画结束等）提供统一机制

**非目标（明确不做）**：
- 字符串/Type 键总线——《简化版UI框架设计》的禁令保留其精神
- 线程安全 / 异步派发 / 帧末队列——单线程游戏，同步派发到底
- 取代 BattleEvents / MetaEvents / UiEvents——共存，见第五节

---

## 二、形态选型

| 方案 | 判定 | 理由 |
|---|---|---|
| **struct 事件 + 泛型订阅** | **采纳** | 类型即键：`Subscribe<EntranceAnimDone>(h)`。零字符串零反射；载荷字段编译期全检（拼错/漏字段直接编译不过）；新事件=新 struct 定义，定义即文档 |
| enum EventId + object 载荷 | 否决 | ID 编译期安全，但载荷是 object，转型错了运行时才炸——把一半类型安全丢了 |
| 字符串键总线 | 禁止 | 原禁令不变：事件名拼错编译器不报错 |

事件 struct 的形态约定：一律 `readonly struct`、名词过去时（`EntranceAnimDone`）、载荷字段最小化、定义在 GameEvents 程序集中（谁发送谁定义，集中存放便于盘点）。

## 三、API 与派发模型【本期】

```csharp
// GameEventBus.cs —— 全局唯一总线（静态类，纯 C#，零 UnityEngine）
public static class GameEventBus
{
    public static void Subscribe<T>(Action<T> handler) where T : struct;
    public static void Unsubscribe<T>(Action<T> handler) where T : struct;
    public static void Send<T>(in T evt) where T : struct;   // 立即同步派发，按订阅序
    public static void ClearAll();                           // 仅测试/战斗重置用，业务禁调
}
```

- **派发时机：立即同步**。`Send` 直接按订阅顺序回调——栈直白、可断点、与战斗核心同步结算模型天然契合。
- **重入硬禁**：订阅者回调内再 `Send` 抛 `InvalidOperationException`。同步链式派发是时序灾难的源头（A 处理中触发 B，B 又触发 A），用一行纪律挡住；确需联动，回调里做标记、返回后自行处理。
- **线程模型**：不承诺线程安全（游戏单线程使用；主线程约定写入本文）。

## 四、生命周期纪律

静态总线跨场景/跨战斗存活——**订阅/退订必须成对**（与 UI 框架文档对静态事件的告诫同源）：

- 战斗核心：`BattleSession` 构造时订阅、`Dispose` 时退订【本期实现该模式】
- 窗口类：照 UI 框架铁律 OnShow 订阅 / OnHide 退订
- `ClearAll` 仅测试用：每条用例开头清理，防跨用例串扰

---

## 五、与三分域静态事件的关系

**共存，不迁移**（本期决策）：

| 通道 | 职责 |
|---|---|
| `BattleEvents` / `MetaEvents` / `UiEvents`（静态 C# event） | 各域内广播"既成事实"，契约见 UI 框架文档，**维持不动** |
| `GameEventBus`（全局 struct 事件） | 跨域与新需求——本期仅表现事件（表现层→战斗核心的时序回调） |

理由：三分域工作良好、UI 契约稳定；全局总线先用表现事件证明价值。**远期路线【预留】**：某域事件若需要跨模块可见，逐个迁移为 struct 事件——机制不变，只换声明。

## 七、收拢

> **类型即键，同步到底，订阅退订成对，回调内不再 Send。**
> 全局总线是项目公共设施——新增事件先问"这真的是跨域/时序回调吗"，域内广播继续走各域静态事件类。
